---
name: GitHubへの保存経路
description: GitHubの連携APIと既存CLI認証が一致しない環境での確認方針
---

GitHubのソース管理連携が認識・追加されていても、連携APIから接続を取得できない一方で、既存のGitHub CLIから操作できる場合がある。

**Why:** この環境では連携API経由の接続取得が空のままだったが、認証済みCLIはアカウント確認・非公開リポジトリ作成・pushを実行できた。接続の再確認を繰り返しユーザーに依頼する必要はなかった。

**How to apply:** 連携APIが使えないときは、秘密情報を探索・表示せず、既存のCLIで認証済みのアカウントを確認できるか調べる。確認できた場合のみ、そのアカウントで依頼された操作を行う。ワークスペースの既存Git管理を変更する必要のない一回限りの保存は、一時的な独立リポジトリから行える。CLIの認証が今後も有効とは仮定しない。
